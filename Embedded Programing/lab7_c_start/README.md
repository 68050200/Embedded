## รันแต่ละ Lab

เปิด `src/main.c` แล้วแก้บรรทัดบนสุด

```c
#define RUN_LAB 1      /* เปลี่ยนเลขตาม Lab ที่กำลังทำ */
```

| ค่า | สิ่งที่รัน |
|---|---|
| 1 | Lab 1 — struct |
| 2 | Lab 2 — struct + pointer |
| 3 | Lab 3 — union |
| 4 | Lab 4 — bit-field |
| 5 | Lab 5 — function pointer |
| 6 | โจทย์ท้าทายรวม |
| 0 | รันทุก Lab ต่อกัน |

จากนั้นสั่งรันด้วยวิธีใดก็ได้

- กดปุ่ม **Build (เครื่องหมายถูก)** แล้วกด **Upload (ลูกศรขวา)** ที่แถบล่าง
  สำหรับ environment `native` ปุ่ม Upload คือคำสั่ง "รันโปรแกรม" ไม่ได้ส่งไปบอร์ดที่ไหน
- หรือพิมพ์ในเทอร์มินัลของ VS Code ว่า `pio run -t exec`
- หรือใส่เลข Lab ต่อท้ายตอนรันไฟล์ที่คอมไพล์แล้ว เช่น `.pio/build/native/program 3`

ผลลัพธ์ขึ้นในเทอร์มินัลด้านล่างทันที **ไม่ต้องเปิด Serial Monitor และไม่ต้องเสียบสายอะไร**

## ถ้า PlatformIO ฟ้องว่าหาคอมไพเลอร์ไม่เจอ

environment `native` เรียกใช้คอมไพเลอร์ที่มีอยู่ในเครื่อง

| ระบบ | วิธีแก้ |
|---|---|
| macOS | เปิด Terminal พิมพ์ `xcode-select --install` แล้วกดติดตั้ง |
| Linux | `sudo apt install build-essential` |
| Windows | ติดตั้ง MinGW-w64 หรือใช้ทางลัดข้างล่าง |

**ทางลัดที่ใช้ได้ทันทีทุกเครื่อง** ถ้าติดปัญหาแล้วไม่อยากเสียเวลาในคาบ
เปิด [onlinegdb.com/online_c_compiler](https://www.onlinegdb.com/online_c_compiler)
แล้ววางเนื้อไฟล์ `lab1.c` ถึง `lab5.c` ลงไปทีละไฟล์ พร้อมเติม `int main(void){ lab1_run(); return 0; }`
ต่อท้าย และลบบรรทัด `#include "labs.h"` ออก เท่านี้ก็รันได้เหมือนกันทุกอย่าง

## วิธีทำงานในแต่ละ Lab

แต่ละไฟล์แบ่งเป็น 3 ส่วนเหมือนสัปดาห์ที่แล้ว

1. **ส่วนที่ 1 ตัวอย่างให้อ่านและรัน** — อ่านให้เข้าใจก่อน แล้วรันดูผลจริง
2. **ส่วนที่ 2 ลองทำเอง** — เติมโค้ดตรงที่เขียนว่า `TODO` นี่คือส่วนที่ให้คะแนน
3. **ส่วนที่ 3 โจทย์ท้าทาย** — สำหรับคนที่เสร็จก่อน ไม่บังคับ แต่มีคะแนนพิเศษ

**ท้ายไฟล์ทุกไฟล์มีบล็อก "ตรวจด้วยตัวเอง"** บอกไว้ว่าผลรันที่ถูกต้องคืออะไร
รันเสร็จแล้วเลื่อนไปดูท้ายไฟล์ เทียบตัวเลขเอง ถ้าตรงแปลว่าผ่าน ไม่ต้องรอใครมาตรวจ

## ติดปัญหาบ่อย

| อาการ | ทางแก้ |
|---|---|
| `undefined reference to lab1_run` | ไฟล์ `.c` ต้องอยู่ในโฟลเดอร์ `src` เท่านั้น |
| `expected ';' before '}'` | ลืมเซมิโคลอนหลังปีกกาปิดของ `struct` — ข้อผิดพลาดอันดับหนึ่งของคาบนี้ |
| `request for member 'temp' in something not a structure` | ใช้ `.` กับตัวแปรที่เป็นพอยน์เตอร์ ต้องใช้ `->` |
| Build ผ่านแต่ไม่เห็นผลอะไรเลย | ยังไม่ได้กด Upload หรือยังไม่ได้สั่ง `pio run -t exec` |
| แก้ `RUN_LAB` แล้วผลไม่เปลี่ยน | ยังไม่ได้ Build ใหม่ กด Build ก่อนแล้วค่อย Upload |
