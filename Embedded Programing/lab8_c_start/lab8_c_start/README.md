# Lab ครั้งที่ 8 — พอยน์เตอร์ หน่วยความจำ และการคุมขาจริง

51423364 การเขียนโปรแกรมสำหรับระบบสมองกลฝังตัว
ศุกร์ที่ 28 สิงหาคม 2569 เวลา 13:00–15:50 น. ห้อง M-505
**คาบนี้ใช้บอร์ด ESP32 จริง ทำงานกันเป็นกลุ่ม 2–3 คน**

## เรื่องของคาบนี้

สามสัปดาห์ที่ผ่านมาโค้ดของเราพิมพ์ตัวเลขออกหน้าจออย่างเดียว วันนี้จะเป็นวันแรกที่โค้ดของเราไปทำให้ของจริงติดและดับ

เส้นเรื่องคือ **"ที่อยู่บางอันบนบอร์ดนี้ ไม่ใช่ตัวแปร แต่คือขาไฟจริง"**

- Lab 1–4 ทำความรู้จักพอยน์เตอร์และหน่วยความจำให้แน่นก่อน
- Lab 5 คุมขาด้วยฟังก์ชันสำเร็จรูป `digitalWrite`
- Lab 6 เปิดฝาดูว่าข้างใน `digitalWrite` ทำอะไร แล้วทำเองด้วยพอยน์เตอร์ + bitwise

## เตรียมของก่อนเริ่ม

| ของ | จำนวนต่อกลุ่ม |
|---|---|
| บอร์ด ESP32 DevKit | 1 |
| สาย USB ที่ส่งข้อมูลได้ (ไม่ใช่สายชาร์จอย่างเดียว) | 1 |
| ปุ่มกด หรือสายจัมเปอร์ 1 เส้น | 1 |
| **ไม่ต้องมี LED ภายนอกหรือ breadboard เลย** ทุก Lab ใช้ LED บนบอร์ดหลอดเดียว | - |

ถ้าไม่มีปุ่ม ใช้สายจัมเปอร์แตะระหว่างขา **GPIO4** กับ **GND** แทนได้เลย

## เปิดโปรเจกต์

1. แตกไฟล์ `lab8_c_start.zip` ไว้ในโฟลเดอร์ที่ไม่มีชื่อภาษาไทยและไม่มีเว้นวรรค
2. เปิด VS Code → `File > Open Folder...` → เลือกโฟลเดอร์ **lab8_c_start**
3. รอ PlatformIO โหลดโปรเจกต์ **ครั้งแรกจะโหลดชุดเครื่องมือ ESP32 นานประมาณ 5–10 นาที ต่อเน็ตไว้และปล่อยให้โหลดไปพลาง ๆ**

## รันแต่ละ Lab

เปิด `src/main.cpp` แล้วแก้บรรทัดบนสุด

```c
#define RUN_LAB 1      /* เปลี่ยนเลขตาม Lab ที่กำลังทำ */
```

| ค่า | สิ่งที่รัน | ใช้บอร์ดไหม |
|---|---|---|
| 1 | พอยน์เตอร์เบื้องต้น | ดูผลทาง Serial |
| 2 | พอยน์เตอร์กับอาเรย์ | ดูผลทาง Serial |
| 3 | สตริงและตัวปิดท้าย | ดูผลทาง Serial |
| 4 | หน่วยความจำบน MCU | ดูผลทาง Serial |
| 5 | GPIO ครั้งแรก | **LED กะพริบจริง** |
| 6 | เขียนรีจิสเตอร์ตรง ๆ | **LED กะพริบจริง** |
| 7 | โจทย์ท้าทายรวม | **LED + ปุ่ม** |
| 0 | รันทุก Lab ต่อกัน | |

จากนั้นกด **Upload (ลูกศรขวา)** ที่แถบล่าง แล้วกด **Serial Monitor (ปลั๊กไฟ)** ตั้ง baud **115200**
ถ้าหน้าจอว่าง ให้กดปุ่ม **EN** หรือ **RESET** บนบอร์ดหนึ่งครั้ง

## ขาที่ใช้

แก้ได้ที่ `include/labs.h` ที่เดียว ถ้าบอร์ดของกลุ่มใช้ขาอื่น

```c
#define LED_PIN     2    /* LED บนบอร์ด ส่วนใหญ่อยู่ที่ GPIO2 */
#define SENSOR_PIN  4    /* ขาอินพุต ต่อปุ่มหรือแตะสายลง GND */
```

บางบอร์ด LED อยู่ที่ GPIO5 หรือไม่มี LED บนบอร์ดเลย ถ้ารัน Lab 5 แล้วไม่เห็นอะไรติด
ลองเปลี่ยนเป็น 5 ก่อน ถ้ายังไม่ติดให้ต่อ LED ภายนอกที่ GPIO2 ผ่านตัวต้านทาน 220Ω ลง GND

## ติดปัญหาบ่อย

| อาการ | ทางแก้ |
|---|---|
| Upload ไม่ผ่าน หาพอร์ตไม่เจอ | เปลี่ยนสาย USB เป็นเส้นที่ส่งข้อมูลได้ก่อนเสมอ เป็นสาเหตุอันดับหนึ่ง |
| Windows ยังหาพอร์ตไม่เจอ | ต้องลงไดรเวอร์ CP210x หรือ CH340 ตามชิป USB บนบอร์ด |
| ค้างที่ `Connecting.....___` | กดปุ่ม **BOOT** ค้างไว้ตอนที่ขึ้นข้อความนี้ แล้วปล่อยเมื่อเริ่มอัปโหลด |
| Serial Monitor ว่างเปล่า | ตรวจ baud ว่าเป็น 115200 แล้วกดปุ่ม EN บนบอร์ด |
| ตัวอักษรเป็นขยะตอนเริ่ม | ปกติ เป็น boot log ของชิปที่ความเร็วอื่น ข้ามไปได้ |
| LED ไม่ติดใน Lab 5 | เปลี่ยน `LED_PIN` ใน `labs.h` เป็น 5 หรือต่อ LED ภายนอก |
| `undefined reference to lab1_run` | ไฟล์ต้องอยู่ในโฟลเดอร์ `src` เท่านั้น |
| บอร์ดรีเซ็ตตัวเองวนไป | มักเกิดจากอ่านพอยน์เตอร์ที่เป็น NULL หรือเขียนเลยขอบอาเรย์ |

## สิ่งที่ต่อยอดมาจากสัปดาห์ก่อน

- **Lab 5** เอา `struct` กับ `bit-field` จากครั้งที่ 7 มาเก็บสถานะขาจริง
- **Lab 6** เอา `bitwise` จากครั้งที่ 6 มาเซ็ตบิตในรีจิสเตอร์ฮาร์ดแวร์
- **โจทย์ท้าทาย** รวมทั้ง struct, พอยน์เตอร์, อาเรย์ และ GPIO ไว้ในโปรแกรมเดียว
